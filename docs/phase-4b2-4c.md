## Engineering

The same scene, renderer, GSAP ticker, Lenis, ScrollTrigger, CameraRig and AvatarRig remain. No extra canvas, independent animation clock, per-frame React state, audio or external inference calls were added.

The existing project progress interval 0–1 remains the YatraLok/Prisha contract. DOJ appends 1–1.64, internally mapped to 0–1. Existing project positions and scroll budget are unchanged: 22 desktop / 18 mobile / 12 reduced-motion viewport heights. DOJ adds 14.08 / 11.52 / 7.68 respectively. Restoration and direct review URLs convert between the extended timeline and this preserved progress coordinate. Initial CSS reserves the exact full scroll extent.

Every query/chunk/context/response transform and light state is derived from progress, not elapsed time or one-shot callbacks. The commerce fade samples its frozen material state and reconstructs reversibly. DOJ geometry is created only when its preload threshold is reached. Images preload after project progress 0.925; Prisha releases after 1.075. Reverse traversal restores the right namespaces. Failed or late image loads retain the existing cache protections. No Holo media is requested.

New chunks and line marks use instancing. The existing scene disposer handles their geometries, materials and instance buffers. The image cache disposes source textures; the Prisha environment disposes its four small generated label textures. DPR caps remain 1.5 desktop / 1.25 mobile.

Mobile uses shorter travel, fewer document groups, a narrower knowledge layout, conversation-area crops and separate camera keys. Reduced motion uses sequential real product images and a simple SVG question/context/response interpretation, with no WebGL or large camera flight. WebGL context loss uses the same fallback and preserves progress.
